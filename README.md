# Moonlit Dock Heist

A complete, original top-down stealth game that plays offline in a desktop
browser. You are a hooded thief in a harbour yard at full moon: slip past
patrolling guards and their bright amber vision cones, hide behind crates and
in bushes, pocket the glowing loot, and reach the glowing exit — unseen.

- 3 levels (Moonlit Dock, Lantern Warehouse, The Captain's Vault), level select
- Guards with patrol routes, sweeping vision cones, suspicion that builds and
  fades, chase and search behaviour
- Cover that blocks sight (walls, crates) and bushes that hide you; sneaking
  (Shift) is slow and quiet, walking is loud enough for guards to hear
- Alarm meter, timer, loot counter, hints (H), pause (P), restart (R), sound (M)
- All art drawn in code and all sound synthesized with WebAudio — no assets, no network

Play it: open `game/index.html` in desktop Chrome, or serve `game/` with any
static server. Move with WASD or arrow keys, hold Shift to sneak.
